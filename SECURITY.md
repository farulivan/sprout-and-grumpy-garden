# Security

Sprout & the Grumpy Garden is a static browser game. There is no server, no account and no sign-in; the
only thing it stores is its own save, in the player's browser.

## Reporting a vulnerability

Please report it privately, through GitHub:
[**Report a vulnerability**](https://github.com/farulivan/sprout-and-grumpy-garden/security/advisories/new)
(under the repository's **Security** tab). Please don't open a public issue for it.

Say what you found, where, and how to reproduce it. I aim to reply within 7 days.

## What gets fixed

- **The live game**, built from `main` at https://sprout.farulivan.com: yes.
- **The first version**, tag `v1.0.0` at https://sprout-v1.farulivan.com: no. It is kept as it was, so
  the two can be compared.
